# ChatGPT Response Sound

**中文** | [English](README_EN.md)

一个极简的 Firefox 扩展：当 ChatGPT Web 显示后台回复完成通知时，播放一次简短提示音。

## 为什么做这个扩展

同时运行多个 ChatGPT 标签页时，后台回复完成后的页面通知很容易被错过。这个扩展只做一件事：**当 ChatGPT 自己显示一条新的后台完成通知时，响一下。**

## 设计原则

- 目前仅支持 Firefox。
- 仅运行于 `https://chatgpt.com/*`。
- 不需要账号、后端服务或网络请求。
- 不包含统计、跟踪或遥测。
- 不提供弹窗、设置页、历史记录或通知中心。
- 直接监听 ChatGPT Web 自己产生的后台回复完成通知；每条新出现的可见通知只触发一次声音。
- 每个标签页独立工作，不进行跨标签页去重：两个标签页分别出现完成通知，就分别响一次。
- 不推断普通前台回复的完成状态；前台可见回复完成但没有产生完成通知时，不会播放声音。
- 如果 ChatGPT 改版导致无法识别完成通知，扩展会保持静默，而不是猜测回复状态。

## 临时安装与测试

1. Clone 或下载本仓库。
2. 在 Firefox 中打开 `about:debugging#/runtime/this-firefox`。
3. 点击 **加载临时附加组件…**。
4. 选择仓库中的 `manifest.json`。
5. 重新加载已经打开的 `chatgpt.com` 标签页。

Firefox 重启后会移除临时加载的扩展。等实现经过实际使用验证后，再考虑正式打包和签名。

## 使用方式

正常使用 ChatGPT 即可。当当前标签页出现 ChatGPT Web 自己产生的后台回复完成通知时，扩展会播放一次短提示音。

每个标签页互相独立。如果两个标签页先后出现完成通知，会分别响一次。普通前台可见回复如果没有产生这类通知，则不会响。

## 已知限制

本项目依赖 ChatGPT Web 当前的页面通知实现。OpenAI 可能随时调整相关 UI；如果通知结构发生变化，扩展可能需要更新。

设计上优先选择“失效时不响”，而不是为了保持响铃而降低完成判断的准确性。

## 隐私

所有逻辑都在浏览器本地运行。扩展不会收集、上传或保存对话内容，也不会发送网络请求。
